# 👨🏻‍💻 Customer Behavior Data Analytics Project

## 📊 Python | SQL | Power BI | Customer Analytics

An **end-to-end Data Analytics portfolio project** focused on analyzing customer shopping behavior, identifying purchasing patterns, understanding customer segments, and transforming raw data into actionable business insights.

This project demonstrates a complete analytics workflow similar to the responsibilities of a professional **Data Analyst / Business Intelligence Analyst**, including:

- 🐍 Data Cleaning & Exploratory Data Analysis using **Python**
- 🗄️ Data Analysis & Business Question Solving using **SQL**
- 📊 Interactive Dashboard Development using **Power BI**
- 📈 Customer Segmentation & Behavioral Analysis
- 💡 Business Insight Generation
- 📄 Reporting & Stakeholder Presentation

---

## 📌 Project Overview

Businesses generate large amounts of customer transaction data, but raw data alone does not provide meaningful insights.

The objective of this project is to transform customer shopping data into useful business intelligence that can help organizations better understand:

- Customer purchasing behavior
- Customer demographics
- Spending patterns
- Product preferences
- Customer loyalty
- Subscription behavior
- Discount usage
- Purchase frequency
- Revenue-driving customer segments

The project follows a complete analytics workflow:

**Raw Data → Python → SQL Database → SQL Analysis → Power BI → Business Insights & Recommendations**

---

## 🎯 Project Objectives

The primary objectives of this project are to:

- Clean and prepare raw customer shopping data for analysis.
- Perform exploratory data analysis to understand distributions and relationships.
- Load transformed data into a relational SQL database.
- Write SQL queries to answer business-related questions.
- Analyze customer segments and purchasing patterns.
- Identify important revenue and customer behavior trends.
- Build an interactive Power BI dashboard.
- Translate analytical findings into actionable business recommendations.
- Present insights in a format understandable to business stakeholders.

# 🚀 How to Run the Project

## 1. Clone the Repository

```bash
git clone https://github.com/Pradesh101/-customer-trends-data-analysis-SQL-Python-PowerBI.git customer-behavior-analysis
```

Navigate to the project directory:

```bash
cd customer-behavior-analysis
```

---

## 2. Run the Python Analysis

Open:

```text
Customer_Shopping_Behavior_Analysis.ipynb
```

Run the notebook to:

- Import the dataset
- Explore the data
- Clean the dataset
- Transform variables
- Perform exploratory analysis
- Prepare the data for SQL

You can run the notebook using:

- Jupyter Notebook
- JupyterLab
- VS Code
- Google Colab

---

## 3. Load the Dataset into SQL

Create a database using:

- MySQL
- PostgreSQL
- Microsoft SQL Server

Use the Python notebook to load the cleaned dataset into the database.

Then open:

```text
customer_behavior_sql_queries.sql
```

Run the queries to analyze customer behavior and answer the business questions.

---

## 4. Connect SQL to Power BI

Open Power BI Desktop and connect it to the SQL database.

Then open:

```text
customer_behavior_dashboard.pbix
```

Use the dashboard to explore customer trends, KPIs, segments, and purchasing behavior.

---

## 5. Create the Business Report & Presentation

After completing the analysis:

- Summarize the most important findings.
- Translate technical findings into business insights.
- Develop actionable recommendations.
- Create a stakeholder presentation.
- Use visualization and storytelling to communicate the results.

A presentation can also be created using tools such as **Gamma AI**.
